NEXA Admin (Decap CMS)

Honest status: this admin is NOT live yet. Decap CMS edits files in the GitHub repository Nexa1st/nexa.1st (branch main). It activates only after:

  1. The owner manually creates the GitHub repo Nexa1st/nexa.1st and pushes this project.
  2. An authentication route is connected: Netlify Identity + Git Gateway, or a GitHub OAuth app / Decap proxy (see CMS-GUIDE.md).

Until then, this page is a noindexed placeholder and no login is possible — repository permissions on GitHub are the real auth gate. Full instructions: CMS-GUIDE.md in the project root.
